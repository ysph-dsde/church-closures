## Overview

The Church Closure Dashboard is intended to dynamically display metrics describing church closures down to the tract level over user-provided date ranges. Users can then select regions to zoom-in on socioeconomic information about that area alongside these church closure metrics. [Shelby Golden, MS](https://www.linkedin.com/in/shelby-golden/) was contracted to review the previously outlined data cleaning, validation, and harmonization methods employed by [Dr. Insang Song](https://sigmafelix.wixsite.com/mysite); outline preparation steps implementing changes and improvements; and prepare metrics for the dashboard's dynamic geospatial visualization.

This codebase includes a GitHub Pages website that summarizes and interprets findings, outlines suggested changes and limitations, and assesses algorithm performance. Scripts include detailed notes explaining what the code is doing and provide guidelines and steps to help subsequent analysts reproduce results or modify the process for improvements or other applications.

**Project PI:** [Professor Yusuf Ransome](https://ysph.yale.edu/profile/yusuf-ransome/) 

This codebase was relocated to Professor Ransome's [SOCAH Lab](https://github.com/SOCAH-Lab) GitHub Organization from the [ysph-dsde](https://github.com/ysph-dsde) GitHub Organization. At the time of relocation, not all scripts or report pages had been completed. As a result, while this repository has been archived, it is not intended for use. Refer to the new repository for the most current and complete version of this project.
